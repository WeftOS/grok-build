# Security Policy

Report vulnerabilities privately through GitHub Security Advisories on the
WeftOS org repository (Security tab, "Report a vulnerability").

Do not open public issues for security reports. Include the affected version or
commit, steps to reproduce, and the impact you expect. We will acknowledge the
report and keep you updated until it is resolved.

Vulnerabilities in code that Tapestry inherits unchanged from the upstream
project it was modified from may also need to be reported to that project.
